Sketchpad is not just a set of drawing tools. The preservation target is Sutherland’s assembly program, its ring structures, and the TX-2 that executed it.

What this build does — and does not — execute
The Console is a new interactive reconstruction. The Assembly and Debugger workspaces execute a documented subset of actual TX-2 instructions. The complete surviving Sketchpad listings do not currently assemble or boot here. Missing behavior is reported rather than silently replaced.

Working at the console
This is a modern reconstruction beside an instruction-level TX-2 research debugger, not the original program running in emulation.
Physical console
Move the pointer onto the CRT, press D / DRAW, move to the endpoint, then press Enter / STOP. Nearby points share topology. For an arc, press C / CEN CIR at its center, move to the start and press DRAW. T starts moving text; type and press STOP. N starts a scalar number. HOLD ignores one pen flick; the pen icon flicks the pen away.
Drawing workbench
Open the drawer for modern tools: L two-click line, C two-click circle, A three-click arc, and inspectors. Keyboard shortcuts switch with the drawer.
Edit
V select. Drag a point to move it; the solver updates constrained geometry. Shift-click for multiple selection. M moves whole objects. F fixes selected points. Delete removes selected geometry.
Constrain and instance
Select one line for H, V or Length; two lines for Equal, Parallel or Perpendicular. Select points for a coincident constraint. Define master copies your selected entities into a picture; Insert places a live instance.
Navigate
Wheel zooms around the pointer. Middle-drag or Space-drag pans. Escape cancels. Ctrl/⌘ Z undoes. Fixed points are excluded from solver variables; direct point dragging releases a fixed point.
Machine workbench
Choose a diagnostic and Assemble & load. Step executes one machine instruction. Reverse restores processor, memory, and device state. Native M4 and scope diagnostics are included. The scope profile models instruction-level INOUT handshakes, not circuit timing. Address dots are breakpoints. The STOP labels in examples are debugger breakpoints, not invented TX-2 halt opcodes.
Original listing retrieval requires network access. Everything else runs locally. No API keys, account, backend service, or external JavaScript library is required.
